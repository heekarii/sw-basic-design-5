# 25-2 소프트웨어설계기초 001분반 5조 repository
사용 언어 : Unity 6(6000.0.58 LTS, 3D URP)

사용 에셋<br>
몬스터 에셋(원본) : https://sketchfab.com/search?q=robot&type=models
(몬스터 에셋은 전   부 찾은걸 쉐이더 적용해서 사용하였음, 일부 몬스터는 본을 때거나 마스크 하는 식으로 사용)

몬스터 및 캐릭터 애니메이션
캐릭터 - 믹사모
펀치로봇 - 믹사모
쥐로봇 - 애니메이션 x
레이저 로봇 - 애니메이션 x
불릿 로봇 - 블랜더에서 본 삽입해 애니메이터로 제작
파이어봇 - 애니메이션 x
에어로봇 - 애니메이션 x
레이저 드론 - 애니메이션 x
전기창 로봇 - 유니티 내에서 애니메이터로 제작
체인소봇 - 믹사모
ai봇 - 애니메이션 x
보스 - 유니티 내에서 애니메이터로 제작

sfx - sfx는 pixabay 음향 효과로 서칭, 필요한 부분 자르거나 소리 겹쳐서 사용
소리 겹쳐서 사용, 잘라서 사용한 sfx - 제론, 불릿로봇, 파이어봇, 레이저 로봇

vfx 
유니티 에셋 스토어 - fire imapct pack, Effect pack, impack pack
이펙트는 프리팹, 또는 오브젝트들을 합치거나 빼는 형식으로 사용했음(+쉐이더 적용)

ui - 아이콘 및 대화창 - 구글링 + 색감 조정
배경 - 인게임 맵에서 각도 조정하여 실제 촬영 + 포스트아포칼립스 느낌의 배경들 유니티 에섯 스토어에서 다운로드

맵, 건물들 
맵 자체는 하나의 에셋이고, 기획과 상의하여 건물 배치(삭제 OR 추가) + 장애물 설치 및 제거  + 베이크 처리하였음
게임 진행에 방해가 되는 오브젝트들은 정리하였고, 너무 단조롭게 보이지 않기 위해 게임에 영향을 미치지 않는 선에서 오브젝트들을 추가했음
탈출 건물 및 정비소 건물 - https://sketchfab.com/search?q=building&type=models
맵 배경은 쉐이더를 통해 약간 어두운 계열로 조정하였음
